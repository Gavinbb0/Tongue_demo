# 舌康舌象记录 Demo（中文版）

这是一个面向患者的中文移动端交互原型，围绕长期舌象记录、照片可见特征整理和复诊前信息准备展开。界面按照 iPhone 17 Pro 尺寸统一设计，并提供基础版与高级版两种体验。

## 在线体验

[打开公开演示](https://shekang-daily.yuanbaiiscool.chatgpt.site)

当前仓库版本：**中文版 v3.0**

## 示例病例

整个 Demo 使用同一组虚构演示资料：

- 患者：李女士，48岁
- 示例医院编号：MASLD-10482
- 随访周期：2026年6月1日至8月10日
- 下次预约：2026年8月18日
- 舌象变化：舌体颜色无持续变化；舌苔覆盖范围较基线持续增加，主要集中在舌中部
- 患者记录：过去两周疲劳感增加，漏服药物3次
- 示例临床资料：ALT 58 U/L、AST 36 U/L、血小板210 × 10⁹/L、FIB-4 1.08

以上人物、编号和数据均为虚构演示内容，不对应真实患者。

## 已实现功能

- 每日舌象拍摄与记录
- 模拟照片质量检查和舌象可见特征整理
- 历史舌象、生活情况及临床资料记录
- 基础版精简报告和高级版深度报告
- 30天舌象变化趋势
- 根据舌象AI结果与健康记录生成复诊前情况
- 可编辑近期情况、主要担忧和想向医生说明的内容
- 高级版“供医生查看的复诊摘要”示例
- 医院关怀计划、每日提醒、隐私与数据说明

## 基础版与高级版

| 功能 | 基础版 | 高级版 |
| --- | --- | --- |
| 每日舌象记录 | 支持 | 支持 |
| 单次舌象报告 | 3项核心特征 | 5项特征及纵向变化 |
| 30天趋势 | 精简趋势 | 深度趋势与辅助信息 |
| 复诊前情况整理 | 近期简要概括 | 整合随访期舌象、患者自述和临床资料 |
| 供医生查看的复诊摘要 | 不提供 | 支持预览 |

## 本地运行

需要 Node.js 22.13.0 或更高版本，以及 pnpm 11。

```bash
git clone https://github.com/Gavinbb0/Tongue_demo.git
cd Tongue_demo
pnpm install --frozen-lockfile
pnpm dev
```

生产构建与类型检查：

```bash
pnpm exec tsc --noEmit
pnpm build
```

## 使用说明

这是课程项目的患者端界面原型。拍摄、AI整理、医院连接和复诊摘要均为模拟交互，不连接真实医院系统，不提供疾病诊断或治疗建议。

本摘要只整理舌象照片中的可见特征和历史记录变化，不能用于诊断MASLD或判断病情进展，也不能代替医院检查和医生评估。
